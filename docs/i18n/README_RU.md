# Autoresearch

[English](../../README.md) | **Русский**

Автономный измеримый цикл экспериментов для Codex.

Задайте Codex числовую цель. Он изучит репозиторий, подтвердит параметры, изменит одну вещь, проверит результат, сохранит улучшение, откатит неудачу и будет повторять цикл до достижения цели.

Подходит для числа падающих тестов, покрытия, ошибок типов, предупреждений, задержки, размера бинарного файла и воспроизводимых результатов проверки безопасности.

## Быстрый старт

Установите в Codex:

```text
$skill-installer install https://github.com/leo-lilinxiao/autoresearch
```

Рекомендуется открыть чистый Git-репозиторий с Full Access:

```bash
codex --dangerously-bypass-approvals-and-sandbox
```

Затем вызовите:

```text
$autoresearch уменьшить error_count из `python3 scripts/score.py` до 0
```

До первой записи Codex подтверждает цель, область изменений, исходное значение, целевое значение, команду измерения, необязательный guard и параллельность.

## Цикл

```text
изучить -> изменить одну гипотезу -> commit и измерение
                                           |
                              улучшение + успешный guard: сохранить
                              иначе: git revert
                                           |
                                    записать и повторить
```

Codex отвечает за гипотезы и код. Управляющий скрипт отвечает за границы Git, измерение, откат и состояние.

## Параллельные кандидаты

| | |
|---|---|
| Изоляция | Одно долгоживущее рабочее дерево Git на слот |
| Распределение | Адаптивное деление между углублением лучшего результата и новыми идеями |
| Вычисления | Объявленный банк ядер и целых машин; каждый кандидат получает выделение |
| Приём | Сериализован; кандидат с устаревшей базой перебазируется и переизмеряется |
| Живость | Аренды, поскольку плоскость управления не владеет процессами воркеров |

Каждый воркер получает одну и ту же общую цель и согласованные решения, а также собственную индивидуальную задачу. Хост без параллельных субагентов занимает по одному слоту и переходит к последовательному выполнению при той же модели состояния.

## Результаты

Незакоммиченные файлы находятся в `autoresearch-results/`:

| Путь | Назначение |
|---|---|
| `run.json` | Подтвержденная неизменяемая конфигурация |
| `events.jsonl` | Только дополняемая история состояния |
| `logs/` | Полный вывод метрик, guards и workers |
| `slots.json` | Состояние слотов, аренды и выданные вычислительные ресурсы |
| `docs/` | Снимки согласованных документов |

`events.jsonl` является единственным источником состояния. Отсутствующие, поврежденные или противоречивые данные вызывают явную ошибку и не восстанавливаются по догадкам.

## История и отчет

```text
$autoresearch show experiment history
$autoresearch export experiment history as TSV
$autoresearch generate an HTML report
```

Таблица и HTML-отчет строятся из проверенных событий. HTML-снимок сохраняется в `autoresearch-results/report.html` и не используется как состояние или источник восстановления.

## Гарантии

- Новый запуск требует чистую именованную ветку Git.
- Один запуск управляет одним репозиторием, одной метрикой и одной целью.
- Каждый эксперимент коммитится; неудачи откатываются через `git revert`.
- Изменения вне области, дрейф Git, неверные метрики, ошибки команд, таймауты и ошибки отката останавливают запуск с путем к логу.
- Статус `complete` появляется только при достижении цели сохраненной метрикой.
